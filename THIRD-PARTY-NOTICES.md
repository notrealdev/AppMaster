## 7-Zip

The Zip module uses `7z.dll`, the engine of [7-Zip](https://www.7-zip.org/), unmodified. It ships in the `Data` folder next to the license text 7-Zip asks to go along with it (`7z-License.txt`, also in this repository).

7-Zip Copyright (C) 1999-2026 Igor Pavlov. Most of the code is under the GNU LGPL; some parts are under the BSD 3-clause and BSD 2-clause licenses, and some LGPL code carries the "unRAR license restriction". The source code of 7-Zip is available at https://www.7-zip.org/.

`7z.dll` is a separate file that AppMaster loads at run time; you can replace it with another build of 7-Zip.
